# HIRED.EXE | Design exploration and decision log

## Starting proposition
The user wanted to apply to Solved Studio with a genuinely playable game about himself going through recruitment. Their nostalgic desktop/browser look suggested the packaging. The distinctive hook is **"The application is the application."**

## Locked direction
- **Name:** HIRED.EXE.
- **Edition 001:** Solved Studio, with tasteful references to its nostalgic desktop styling, without endorsement.
- **Long-term architecture:** a shared game engine, reusable portfolio components and company/role-specific editions. A bespoke recruiter link should not require rebuilding the game.
- **Gameplay:** actual *side-scrolling platforming* with physics, jumps, dashes, collectibles, adversaries, checkpoints and bosses. Not a static CV disguised as a game.
- **Art:** bright, highly detailed, original 16-bit-inspired console-platform art. The approved concept target is `references/approved-gameplay-target.png`. Retro Windows features belong to the outer chrome/HUD.
- **Character:** original pixel Augustus, medium-brown skin, short dark hair, teal jacket, pale shirt, dark trousers, trainers, expressive poses.
- **Four worlds:** Application Alley → Ship It City → Growth Run → Final Interview HQ.
- **Boss themes:** CV Filter → Scope Creep → The Algorithm → final interview as a conversation, not an actual hiring decision.
- **Relevant proof:** unlockable real projects and verified links; demonstrate product judgment, creative background and AI-directed building, not invented independent programming ability.
- **Time goal:** satisfying 4–6 minute run for a busy founder, plus clear skip-to-portfolio action.
- **Responsiveness:** desktop keyboard and usable mobile touch control; speed, clear readability and accessible cues.
- **Visual components:** four world backgrounds; separate terrain and prop components; animation states for character and original hiring-themed enemies; restrained retro OS framing.

## Prior iterations
1. Initial UI prototype about the hiring process.
2. Four-world procedural platformer v0.3 with running/jumping/dashing, hosted separately on Vercel after a sandbox-link loading issue.
3. New image-generated gameplay art and sheets approved by user, followed by four coherent new backdrops and modular sprite art. Those images are in this repository as design and production inputs, not evidence the final game renderer uses them.
4. Repository handover and draft pull request prepared so Work can complete integrated gameplay and rigorous tests.

## Rejected shortcuts
- Do not simply paste one full concept screenshot on top of the game.
- Do not claim labelled concept sheets are uniform production animation frames.
- Do not accidentally clone copyrighted Mario/Sonic graphics.
- Do not fake real employer endorsement, successful hiring decisions or portfolio metrics.
- Do not overfocus on pixel decoration at the expense of a fun, responsive game.
