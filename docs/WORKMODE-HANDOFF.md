## How to work in this repo

- Start with `README.md`, `docs/CONVERSATION-CONTEXT.md`, `docs/ART-BIBLE.md`, `docs/COMPONENTS.md`, `docs/LEVEL-DESIGN.md`, `docs/DELIVERY-INCIDENT.md` and `docs/RELEASE-CHECKLIST.md`.
- Work from the `feat/hired-exe-art-and-game-handoff` branch, not a clean rewrite or old v0.3 archive.
- The actual runnable modular build is `index.html` + `src/` + `styles.css` + `assets/production/`, and companion `art-book.html`. Offline single-file `HIRED-EXE-v0.4-PLAY.html` and `HIRED-EXE-v0.4-ART-BOOK.html` are generated by `tools/build.py`.
- 14 simulation tests pass at the handoff point. They exercise controller/physics outcomes; they do **not** prove the public URL, current employer content or every browser interaction.
- If some large source references or archived prototype attachments are absent from the GitHub branch, retrieve the exact provided `HIRED-EXE-v0.4-PROJECT.zip` handoff file from the current ChatGPT conversation or library, compare SHA-256 and import them. Never reconstruct a user-approved asset from a search result when the exact original is supplied.
- Evaluate code modularity, accessibility and mobile controls. Maintain British spelling and the user's genuine product/creative strengths.

## Definition of done for employer-ready review

- A fresh browser visit to a real HTTPS URL immediately displays the new vivid 16-bit artwork and an Augustus playable sprite, never the old procedural world.
- All four worlds load, move, jump and dash work, bosses and gates can be completed with normal inputs, checkpoints and restart function, game does not produce runtime errors.
- First-time players can skip to truthful portfolio, play with keyboard and mobile touch, access help, pause and resume, and contact the applicant without a false job-offer premise.
- Screenshot evidence is captured at the live URL for all four levels, at least one phone view, title, interview and ending.
- Exact commit, Vercel deployment and test evidence are recorded in PR #1. Clearly distinguish tested, untested and blocked items.
- No merge, production promotion, public employer outreach or application submission without explicit user approval.
